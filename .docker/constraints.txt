# for every policy call (realm/inference/client.py drives

# >=11.0), so the two images could behave differently against the same policy server.
#

# suite ran against -- NOT what isaacsim-kernel 5.1.0.0 declares. isaacsim pins all six exactly

# typing_extensions==4.12.2) and pip prints a resolver conflict for each. That conflict is
# PRE-EXISTING -- it appears identically in every build of this recipe -- and Isaac demonstrably
# runs with these versions. Downgrading to isaacsim's six would silence the warning at the cost
# of shipping a runtime nothing has tested, which is the worse trade for a benchmark.

# CAVEAT, because it bounds what "verified" means here: every automated test drives
# --model_type debug, which returns a canned action and never opens a socket. So the websockets
